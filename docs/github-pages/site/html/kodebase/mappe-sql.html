Kode · src/database/

Indeholder source-of-truth databaseskemaer, schema-værktøjer og test-seeds. MySQL- og PostgreSQL-definitionerne ligger under src/database/, mens testdata holdes separat under src/database/seeds/.

Database-servicens CLI bruger schema-definitionerne til sammenligning, validering og sikre, additive deployment-planer. Seed-data og databasescripts må ikke bruges som kilde til offentliggørelse af rigtige oplysninger.
