Kode · src/test/database/

Python-tests for schema-læsning, schema-sammenligning og sikker deployment-planlægning. Testene dækker databaseværktøjets vigtigste sikkerheds- og parsingregler uden at åbne en live databaseforbindelse.

Testene nedenfor findes i test_schema_management.py og dækker schema-læsning, sammenligning og sikker deployment-planlægning.
