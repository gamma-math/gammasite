Kode · services/*/test/

Service-tests

Pytest-tests for Stripe- og MobilePay/Vipps-værktøjerne. Testene bruger mocked HTTP-svar og kontrollerer CLI- og requestlogik uden at kalde betalingsleverandørernes live-API'er.

Testmoduler

TestmodulFormål
stripe/test/test_stripe_api.py4 tests for API-key og versionsheaders, manglende secret, pagination og filtrering af payout-transaktioner.
vipps/test/test_vipps_connection.py3 tests for access-token-kald, manglende konfiguration og optional idempotency-header.
vipps/test/test_vipps_cli.py2 tests for CLI'ens betalingsreference og krav om gammelt webhook-id.
vipps/test/test_vipps_payments.py4 tests for oprettelse, opslag og capture af betalinger samt afvisning af ugyldig betalingsstatus.
vipps/test/test_vipps_agreements.py4 tests for recurring-konfiguration, aftaleopslag, accept/stop og charge-opslag.
vipps/test/test_vipps_webhooks.py5 tests for registrering, validering, listing, sletning og rotation af webhooks.

Kør testene

Installer først hvert værktøjs requirements i dets eget virtuelle miljø:

py -m venv src/services/stripe/.venv
& .\src\services\stripe\.venv\Scripts\python.exe -m pip install -r src/services/stripe/requirements.txt
py -m venv src/services/vipps/.venv
& .\src\services\vipps\.venv\Scripts\python.exe -m pip install -r src/services/vipps/requirements.txt

Kør derefter testpakkerne fra repositoryets rod:

& .\src\services\stripe\.venv\Scripts\python.exe -m pytest src/services/stripe/test
& .\src\services\vipps\.venv\Scripts\python.exe -m pytest src/services/vipps/test

Testene kræver ikke API-secrets. Live integrationstest skal udføres separat med test-mode credentials og efter leverandørernes rate limits og webhook-regler.
