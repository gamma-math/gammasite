Deploy hjemmesiden

Manuelt workflow til build, test og deployment af GamMaSite.

  1. Åbn Actions i GitHub, og vælg Build and deploy.
  2. Vælg Run workflow, og vælg miljøet TEST eller PROD.
  3. Workflowet klargør .NET 10 og Node.js 22 på Windows.
  4. Deploymentindstillinger og finansforbindelser valideres.
  5. Frontendpakker installeres, React/Vite bygges, og frontendtestene køres.
  6. Backendpakker gendannes, og .NET-testene køres. Testresultater gemmes som et Actions-artifact.
  7. Applikationen publiceres som en self-contained .NET 10-app via MSDeploy.

Hemmeligheder hentes fra GitHub Secrets og vises ikke i dokumentationen.
