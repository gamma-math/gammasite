Root-værktøjer

De vigtigste konfigurations- og arbejdsværktøjer i repositoryets rod. Siden beskriver deres ansvar og kommandoer uden at blande dem sammen med applikationsmapperne.

Værktøjer og konfiguration

FilFormål
MakefileSamler standardkommandoer til restore, build, run, hot reload, publish og oprydning.
.pre-commit-config.yamlAktiverer YAML-kontrol, trailing-whitespace-kontrol og end-of-file-fiksering før commits.
global.jsonFastlægger den .NET SDK-version, som lokale builds og CI skal bruge.
GamMaSite.slnSamler backendprojektet og dets testprojekt i .NET-løsningen.
multiproject.code-workspace.exampleEksempel på en VS Code-workspace med de relevante projektmapper.
.dockerignoreHolder build-konteksten lille ved at udelade lokale miljøer, output og afhængighedsmapper fra Docker-builds.
.gitignore og .gitattributesStyrer lokale artefakter, linjeskift og filer, der ikke skal versionstyres.
CHANGELOG.mdReleasehistorik og noter om større tekniske ændringer.

Make-kommandoer

KommandoFormål
make restoreGendanner NuGet-afhængigheder.
make buildBygger løsningen i Debug-konfiguration.
make runStarter backendens udviklingsserver. Brug ENV=Staging for et andet ASP.NET Core-miljø.
make watchStarter backend med hot reload.
make publishPublicerer løsningen i Release-konfiguration.
make cleanFjerner .NET build- og publish-output. Kør kun kommandoen, når output må genskabes.

Pre-commit

Installer pre-commit i dit lokale Python-miljø, aktivér hooks i repositoryet, og kør dem manuelt ved behov:

py -m pip install pre-commit
pre-commit install
pre-commit run --all-files
