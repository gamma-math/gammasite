Udgiv dokumentationen

Det manuelle workflow bygger og udgiver dokumentationssitet på GitHub Pages.

  1. Push de gennemgåede ændringer til den ønskede branch.
  2. Åbn Actions i GitHub, og vælg Deploy GitHub Pages.
  3. Vælg Run workflow, og start kørslen.
  4. Ved første kørsel skal en repositoryadministrator vælge Settings → Pages → Build and deployment → Source: GitHub Actions.
  5. Følg build- og deploy-jobbet. Ved succes viser Pages-jobbet den publicerede URL.

Workflowet bruger kun de rettigheder, der kræves til Pages-deployment.
