Kode · src/backend/GamMaSite/

ASP.NET Core-applikationen. Controllers eksponerer web- og API-endpoints; services samler domænelogik og integrationer; data- og modelklasser håndterer lagring og domæneobjekter; viewmodels beskriver transportdata.

Filerne nedenfor er projektets egne, versionsstyrede filer. Tredjepart, build-output og lokale konfigurationsfiler er udeladt.
