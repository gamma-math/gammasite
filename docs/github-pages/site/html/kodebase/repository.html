Repositorystruktur

Denne underside giver et samlet overblik over repositoryets topniveau og de vigtigste projektområder. Den er en navigationshjælp på samme måde som strukturoversigten i root-README’en; de enkelte kodeområder har egne detaljerede sider.

Mapper og projektområder

.
|-- .github/
|   `-- workflows/                 GitHub Actions build/deployment workflows.
|-- .vscode/                       Example editor launch/task configuration.
|-- docs/                          Project documentation and protected design references.
|   `-- github-pages/              Primary consolidated documentation site.
|-- src/
|   |-- database/                  Database schemas, schema tooling, and test seeds.
|   |-- backend/GamMaSite/         ASP.NET Core application and deployed web assets.
|   |-- frontend/                  React/Vite source application.
|   |-- services/
|   |   |-- database/               Python schema-management service and database drivers.
|   |   |-- local-development/      Docker Compose stack, seed scripts and local integrations.
|   |   |-- stripe/                 Standalone Stripe API inspection helper.
|   |   `-- vipps/                  MobilePay/Vipps CLI, Docker setup and pytest tests.
|   `-- test/
|       |-- database/               Python unit tests for schema parsing, comparison and deployment safety.
|       |-- GamMaSite.Tests/        Backend unit tests for APIs, services, Identity and Finance validation.
|       `-- frontend/               Node-based frontend tests.
|-- GamMaSite.sln                  Solution file for the backend project.
|-- global.json                    .NET SDK version pin.
|-- Makefile                       Common local build/run commands.
`-- qrcode-1.5.4.tgz               Local QR code package used by the frontend/tooling.

Topniveauets ansvar

OmrådeAnsvarDetaljeret dokumentation
.github/CI/CD, database-deployment og GitHub Pages.GitHub Actions
docs/Teknisk dokumentation og separat designreference.docs
src/database/Source-of-truth SQL, schema CLI-understøttelse og seeds.Database
src/backend/GamMaSite/ASP.NET Core-host, API, Identity og integrationer.Backend
src/frontend/React/Vite-klient og browserbrugerflade.Frontend
src/services/Python-services, Docker Compose og lokale integrationsværktøjer.Services
src/test/Backend-, frontend- og database-tooling-tests.Backendtests, frontendtests og databasetests

Lokale miljøfiler, appsettings med secrets, build-output, virtuelle Python-environments og binære artefakter er ikke en del af den versionsstyrede repositorystruktur.
