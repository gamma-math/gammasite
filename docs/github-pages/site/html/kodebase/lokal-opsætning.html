Start løsningen lokalt

Brug .NET SDK 10, en kompatibel Node-version og MySQL 8 eller nyere.

  1. Hent repositoryet, og gå til projektmappen.
    git clone <repository-url>
cd gammasite
  2. Installer frontendpakkerne, og byg React-klienten.
    cd src/frontend
npm ci
npm run build
  3. Gå tilbage til repositoryroden, og gendan .NET-pakkerne.
    cd ../..
dotnet restore GamMaSite.sln
  4. Start backend og frontend med make run. Du kan også bruge dotnet run --project src/backend/GamMaSite/GamMaSite.csproj.
  5. Kør backend- og frontendtestene.
    dotnet test src/test/GamMaSite.Tests/GamMaSite.Tests.csproj
cd src/frontend
npm test

Lokale konfigurationsfiler og hemmeligheder må ikke committes.
