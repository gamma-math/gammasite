Services og integrationsværktøjer

Hjælpeprogrammer og lokal infrastruktur, som understøtter backend, databaser, betalinger og udvikling. Services-mappen indeholder ikke selve webapplikationen; den samler værktøjer, der kører ved siden af den.

Moduler

ModulFormålDriftsform
database/Python-CLI, som genbruger src/database/scripts/ til diff, validate, plan og deploy af MySQL- og Finance PostgreSQL-schemaer.Lokal Python eller GitHub Actions
local-development/Docker Compose-stack med MySQL, Finance PostgreSQL, app, test-containere, seeds og lokale integrationsprofiler.Docker Compose
stripe/Selvstændigt Python-værktøj til Stripe API-opslag, payout-lister og payout-transaktioner.Lokal Python eller Docker
vipps/CLI til MobilePay/Vipps-betalinger, recurring-aftaler og webhook-registrering, herunder rotation og sletning.Lokal Python eller Docker

Sammenhæng med resten af projektet

  • database/ og src/database/ deler schema-implementeringen, så CLI'en ikke bliver en separat Source of Truth.
  • local-development/ starter den lokale applikation og databaserne med de samme database- og integrationsgrænseflader, som applikationen bruger.
  • stripe/ og vipps/ er manuelle integrationsværktøjer. De erstatter ikke backendens betalingsflows eller webhook-endpoints.
  • Lokale secrets skal ligge i de respektive .env-filer eller i Compose-overrides og må ikke committes.

Den praktiske opstart af Compose-miljøet er beskrevet i Lokal opsætning. Testene for de to eksterne helper-services er samlet på siden Service-tests.
