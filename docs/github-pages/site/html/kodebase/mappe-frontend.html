Kode · src/frontend/

React/Vite-kilde til brugergrænsefladen. app/ starter klienten; pages/ samler sider; components/ og layouts/ genbruger UI; services/ kalder API'er; routes/ styrer navigation; styles/ og utils/ indeholder fælles styling og hjælpefunktioner.

Filerne nedenfor er projektets egne, versionsstyrede filer. Tredjepart, build-output og lokale konfigurationsfiler er udeladt.
