Systemoversigt

Drift og eksterne tjenester

De eksterne løsninger, GamMaSite bruger til drift, data, betaling og finans.

TjenesteRolleAnvendelse i GamMaSite
SimplyWeb- og databasehostingHoster hjemmesiden og den primære MySQL-database, som håndterer brugere, indhold, Identity og øvrige applikationsdata.
Neon TechFinansdatabaseHoster PostgreSQL-databasen til finans, herunder posteringer, konti, posteringsgrupper og importhistorik.
CloudflareBilledarkiv og backup-lagringBruges som objektlager til billeder på hjemmesiden og til backupstorage.
StripeBetalingLeverer produkter, priser og Checkout-sessioner til medlemskaber og øvrige betalinger.
MailgunE-mailleveringSender e-mails fra besked- og skabelonfunktionerne til valgte modtagere.
MobilePayFinanskildeMobilePay-transaktioner importeres som CSV i finansmodulet og kan matches med bankposteringer.
Danske BankBankkildeBankkontoudtog importeres som CSV i finansmodulet. Der er ikke dokumenteret en direkte bank-API-integration.
Google CalendarKalenderfeedLeverer kommende kalenderbegivenheder via den konfigurerede kalenderintegration.
GitHubKode, indhold og automatiseringOpbevarer kildekoden og udvalgt statisk indhold. GitHub Actions bygger og udgiver dokumentationssitet.
