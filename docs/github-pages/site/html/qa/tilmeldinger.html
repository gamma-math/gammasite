Redigér tilmeldinger til et event

Kræver: registrations.edit eller content.edit. Eventarrangører kan redigere deres eget event.

  1. Åbn eventet, og vælg Se tilmeldte.
  2. Hvis du vil tilføje en deltager, skal du søge efter medlemmet, vælge rolle og markere tilmeldingen. Vælg derefter Tilføj.
  3. Redigér rollen eller status direkte på tilmeldingen.
  4. Vælg Afmeld, når en tilmelding skal fjernes.
  5. Funktionen er kun tilgængelig, mens tilmeldingen er åben.
  6. Kontrollér listen, før du forlader siden.
