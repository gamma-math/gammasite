Hvis data kan være kompromitteret

Brug den interne beredskabsplan ved en konkret hændelse.

  1. Begræns skaden: få en autoriseret administrator til at begrænse den mistænkte adgang og skriveadgang.
  2. Stop risikable handlinger: start ikke backup- eller gendannelsesjob, før hændelsen er vurderet.
  3. Dokumentér hændelsen: notér tidspunkt, berørte systemer og synlige ændringer uden at dele følsomme data offentligt.
  4. Vurdér omfanget: afklar berørte data og adgange, herunder om der kan være tale om et persondatabrud.
  5. Gendan kontrolleret: validér en gendannelse i et isoleret miljø efter den interne plan.
  6. Åbn gradvist igen: skift berørte adgange, kontrollér data, og genåbn først normal brug, når situationen er sikker.

Del aldrig adgangskoder, nøgler, backupplaceringer eller kontooplysninger offentligt.
