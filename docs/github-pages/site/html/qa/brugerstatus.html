Skift status for et medlem

Kræver: roles.edit.

  1. Åbn Admin → Medlemmer.
  2. Find medlemmet med søgning eller sortering.
  3. Vælg en status i kolonnen Status: OPRETTET, BETALT, SKYLDER, INAKTIV eller STUDERENDE.
  4. Kontrollér den nye værdi, før du forlader siden.
