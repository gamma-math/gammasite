Send en besked

Kræver: messages.edit.

  1. Åbn Admin → Beskeder.
  2. Vælg skabelon og kanal: e-mail, SMS eller begge dele.
  3. Vælg modtagere via gruppe, rolle, eventdeltagere eller enkeltmedlemmer.
  4. Vælg relevant event eller nyhed, og vælg Generér e-mail.
  5. Gennemgå emne og indhold.
  6. Åbn forhåndsvisningen, og kontrollér modtagerlisten.
  7. Vælg Send besked, og bekræft antallet af modtagere.
