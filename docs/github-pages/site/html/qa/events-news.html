QA · Events og nyheder

Opret eller redigér indhold

Kræver: content.edit. En eventarrangør kan redigere sit eget event.

  1. Åbn Admin, og vælg Events eller Nyheder.
  2. Vælg Opret ny, eller vælg Redigér ved et eksisterende element.
  3. Udfyld titel, slug, status, resumé og tekst.
  4. Udfyld også sted, starttidspunkt og eventuelt sluttidspunkt for events.
  5. For events: tilknyt de relevante betalingslinks, og kontrollér produkt, betalingsudbyder, betalingstype og beløb.
  6. Vælg Gem.
  7. Brug kun PUBLISHED, når indholdet må vises offentligt.
  8. Vælg Se fra oversigten for at kontrollere resultatet.
