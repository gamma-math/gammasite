Opret en beskedskabelon

Kræver: email_templates.edit.

  1. Åbn Admin → Beskedskabeloner, og vælg Opret ny.
  2. Angiv navn, type, emne og indhold.
  3. Hold skabelonen generel og uden følsomme data.
  4. Indsæt kun de understøttede blokke efter behov: {{ContentBlocks}}, {{EventBlocks}} eller {{NewsBlocks}}.
  5. Markér skabelonen som aktiv, og vælg Gem.
  6. Vælg Forhåndsvisning, før skabelonen bruges til en besked.
