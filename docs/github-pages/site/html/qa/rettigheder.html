QA · Roller og rettigheder

Administrér roller

Kræver: roles.edit. Tildel kun den adgang, der er nødvendig for opgaven.

  1. Åbn Admin → Roller.
  2. Vælg en eksisterende rolle, eller vælg Opret ny.
  3. Vælg de medlemmer, der skal tilknyttes rollen.
  4. Aktivér de nødvendige rettigheder, og vælg Gem.
  5. Kontrollér medlemmer og rettigheder.

ADMIN-rollen har alle nødvendige rettigheder og kan ikke slettes. Betalingsadministration er en separat permission.

Adgang til medlemsfunktioner

Medlemsoversigt, kalender, bibliotek, egne betalinger, egen finansoversigt og egen profil kræver login, hvor det er angivet på den enkelte side. Backend validerer altid den endelige adgang.
