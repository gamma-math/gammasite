Finans · CSV-import

Importér finansdata

Kræver: finance.edit.all. finance.view.all giver ikke adgang til import.

  1. Åbn Admin → Finans → CSV-import.
  2. Vælg en autoriseret CSV-fil fra banken eller MobilePay.
  3. Kontrollér importresultatet.
  4. Generér kun afledte posteringer, når importen er kontrolleret.
