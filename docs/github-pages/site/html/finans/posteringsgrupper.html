Finans · Posteringsgrupper

Opret en posteringsgruppe

Kræver: finance.edit.all.

  1. Åbn Admin → Finans → Posteringsgrupper.
  2. Vælg Opret ny gruppe.
  3. Angiv navn og de klassificeringer, formularen kræver.
  4. Gem gruppen, og kontrollér at den kan vælges ved redigering af posteringer.
