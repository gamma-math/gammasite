Finans · Eksport

Eksportér posteringer

Kræver: finance.view.all. Rettigheden giver læseadgang og eksport, men ikke redigering eller import.

  1. Åbn Admin → Finans → Posteringer.
  2. Brug filtrene til at afgrænse visningen.
  3. Vælg eksportfunktionen.
  4. Gem filen sikkert, og del den kun med personer, der har brug for finansdata.
