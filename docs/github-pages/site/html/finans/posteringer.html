Finans · Posteringer

Opret eller redigér en postering

Kræver: finance.edit.all.

  1. Åbn Admin → Finans → Posteringer.
  2. Opret en ny postering, eller åbn en eksisterende.
  3. Udfyld de krævede felter, og vælg posteringsgruppe og konto.
  4. Vedhæft et bilag, når bogføringspraksis kræver det. Bilag må ikke publiceres.
  5. Vælg MobilePay som kilde, når posteringen stammer fra MobilePay.
  6. Kontrollér beløb, dato og klassificering, og vælg Gem.
